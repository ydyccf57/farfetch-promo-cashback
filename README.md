## Common Farfetch promo code problems

### The code is expired

Farfetch says customer service cannot reactivate expired promotional discounts. A code that worked last week is not evidence that it works today.

### The code is region-specific

Farfetch runs localized promotions. A code listed for the UK, Canada, Australia, or another market may not apply to a US order.

### The product is excluded

Luxury brands, special collaborations, sale items, and selected partner inventory may be excluded. Farfetch says it cannot provide one permanent list of excluded brands because eligibility differs between promotions.

### The minimum spend is misunderstood

A promotion may require the threshold to be reached using eligible products only. Taxes, shipping, excluded items, and already-discounted goods may not count.

### Two discounts are already competing

Farfetch says some promotions cannot be used simultaneously. An automatic campaign may be overwritten when another code is entered, leaving the shopper with a lower discount.

### The cashback does not track

Common causes include an existing cart, ad blockers, VPNs, third-party coupon links, switching devices, using the Farfetch app after starting on desktop, or opening a competing affiliate link. ShopBack specifically recommends clearing the Farfetch cart, closing the app, starting again from ShopBack, and completing the order without interruption.
